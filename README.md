# Укради Мутанта!

Прототип браузерной игры. Забери Тунг-Тунг Сахура с постамента в лаборатории и вернись на зелёную площадку базы до конца тревоги. Движение — WASD, обзор — перетаскивание мышью, подбор — E или кнопка «Забрать». На телефоне доступны джойстик и свайп.

## Запуск и проверка без локальной сборки

1. Создай свой репозиторий на GitHub и загрузи исходники вместе с папкой .github. Папки node_modules и dist загружать не требуется.
2. Для публикации открой Settings → Pages и в поле Source выбери GitHub Actions. На GitHub Free Pages доступен для публичного репозитория.
3. В Actions выбери Build and publish playtest → Run workflow. Оставь publish выключенным, чтобы только собрать и протестировать. Включи publish, чтобы получить ссылку на игру в задаче deploy.

Workflow выполняет npm ci, npm test и npm run build на Ubuntu. Готовый HTML5-билд доступен в Artifacts. Его также можно загрузить на itch.io как HTML5 ZIP с index.html в корне. Браузер отрисовывает сцену на устройстве игрока. По умолчанию игра использует облегчённую графику.

## Локальная разработка

Используй Node.js 24 и npm. Выполни npm ci, затем npm run dev. Для проверки выполни npm test и npm run build. Результат сборки находится в dist.
