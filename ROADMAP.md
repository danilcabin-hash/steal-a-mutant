# Дорожная карта

| Этап | Критерий готовности |
| --- | --- |
| 1. Основа | Vite собирает 3D-сцену. Ошибка WebGL отображается в интерфейсе. |
| 2. Карта и управление | Маршрут от базы до комнат лаборатории проходим. Коллизии, камера, WASD и сенсорное управление проверены. Физические Android и iOS входят в мобильную проверку. |
| 3. Мем-персонажи | Одного персонажа можно забрать с постамента и доставить на базу. При истечении таймера он возвращается на постамент. |
| 4. Охрана | Охранники патрулируют, обнаруживают кражу, преследуют и возвращают добычу при поимке. |
| 5. База и экономика | Доставка даёт одного мутанта нужной редкости при наличии места. 12 существ приносят доход. Двойная выдача и отрицательный баланс исключены тестами. |
| 6. Прогресс | Скорость, слоты и доход улучшаются. Коллекция и прогресс переживают перезапуск и миграцию сохранения. |
| 7. Интерфейс и эффекты | Обучение проводит игрока через первый рейд. UI и производительность проверены на целевых экранах. |
| 8. Яндекс Игры | Проверены облачные сохранения, жизненный цикл SDK, прерывание рекламы и начисление наград только по подтверждению. |
