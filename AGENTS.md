# Правила разработки

- Работай по этапам из ROADMAP.md. Сначала проверь предыдущий игровой сценарий.
- Используй строгий TypeScript. Держи жизненный цикл, карту, игрока, камеру и UI в отдельных модулях. Новые модули добавляй вместе с их первой функцией.
- Храни параметры баланса в config. Покрывай экономику, выпадение, выдачу наград и миграции тестами Vitest по мере реализации.
- Обновляй симуляцию через deltaTime, переиспользуй геометрию и материалы, освобождай ресурсы при уничтожении сцены.
- Учитывай клавиатуру, мышь и касания. Проверяй мобильную компоновку и возобновление после потери фокуса.
- Используй оригинальных персонажей и модели. Перед подключением Яндекс Игр сверяйся с официальной документацией.
- Перед сдачей запускай npm run check, npm run build и доступные тесты. Отмечай, на каких устройствах проверена игра.
